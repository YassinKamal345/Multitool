# Windows Multiboot / MultiTool

A lightweight **Windows multitool launcher** developed using Batch scripting.  
The project provides a simple command-line interface to quickly launch frequently used applications from a centralized menu.

This tool was created as a personal utility to improve workflow efficiency on Windows systems.

---

## 📌 Overview

- Menu-driven CLI interface
- Built entirely with Windows Batch scripting
- Uses shortcuts (.lnk) for modular application management
- Clean structure and easy customization

---

## 🛠 Technologies Used

- Windows Batch scripting (`.bat`)
- Windows Command Line
- Shortcut files (`.lnk`)
- Basic CLI UI design (ASCII art, colors)
